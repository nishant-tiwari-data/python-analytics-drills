# Python Analytics Drills & Data Wrangling

A repository tracking practical Python programming for data analysis, focusing on Pandas, data cleansing, and exploratory data analysis (EDA).

---

### 📌 Core Modules

* **Data Cleaning & Auditing (`/data-cleaning`):** 
  * Handling missing/null values (`fillna`, `dropna`, interpolation)
  * String parsing and regular expression cleanup
  * Data type casting, schema checks, and datetime manipulations
* **Data Transformation (`/transformations`):** 
  * GroupBy aggregations, pivot tables, and crosstabs
  * Merging, joining, and concatenating heterogeneous datasets
  * Applying custom vectorized calculations
* **Exploratory Data Analysis (`/eda-notebooks`):** 
  * Summary statistics, distribution analysis, and outlier detection
  * Visualizations using Matplotlib and Seaborn
